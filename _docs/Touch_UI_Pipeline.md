
# 🧭 Пайплайн визуальной разработки интерфейса для Raspberry Pi

## 🔧 Описание устройства

- Фиксированное разрешение экрана (например, **1024×600**)
- Сенсорный ввод (нажатия и жесты)
- Поддержка **звука и микрофона**
- Подключение к интернету и веб-сервисам (например, **API погоды**)
- Разработка и тестирование на **Windows**, затем перенос на **Raspberry Pi**

---

## 🎯 Цель

Создание мультимедийного, тач-дружественного интерфейса в стиле **ретро** или **Minecraft-like** с поддержкой тем,
динамической смены стилей, сеточной вёрсткой и подключением к внешним данным (погода, расписания, системные события).

---

## 🧰 Стек технологий

- **Язык:** Python 3.10+
- **UI:** Kivy + KivyMD
- **IDE:** Visual Studio Code
- **Дизайн макетов:** Figma
- **Графика:** PNG (генерируется нейросетями: Midjourney, DALL·E и т.п.)
- **API-запросы:** requests или aiohttp

---

## 📐 Макеты и графика

- Макеты делаются в **Figma** по фиксированной сетке (например, шаг 32px)
- Каждая тема содержит два набора:
  - **Светлый**
  - **Тёмный** (переключается автоматически по таймеру)
- У каждой версии: отдельные PNG-иконки и `.kv`-стили
- Именование элементов важно: `btn_ok`, `label_temp`, и т.п.

---

## 🔁 Этапы пайплайна

1. **Генерация графики** — фон, иконки, декор
2. **Создание макета в Figma** с учётом сетки и привязок
3. **Экспорт кода** через плагин *Figma to Code* (в формате Flutter)
4. **Конвертация** Flutter-кода в `.kv` с помощью `flutter_to_kv.py`
5. **Интеграция графики и тем** через KivyMD (`theme_cls`, `canvas.before`)
6. **Логика и обработка** событий в `main.py`
7. **Тестирование на Windows** (полноэкранный режим)
8. **Деплой на Raspberry Pi** (через Git/SCP, автозапуск через `systemd` или `xinit`)

---

## 🌗 Темы и стили

- Темы переключаются по **таймеру** или вручную
- В каждой теме:
  - Стили контролов (цвета, отступы, шрифты)
  - Набор PNG-графики
- Хранение: `themes/<имя_темы>/light/` и `themes/<имя_темы>/dark/`
- Управляется через `theme_cls` в KivyMD

---

## 📡 Работа с API

- Подключение к REST API (погода, расписание, синхронизация и т.п.)
- Используется `requests` или `aiohttp`
- Настройки и ключи в `.env`
