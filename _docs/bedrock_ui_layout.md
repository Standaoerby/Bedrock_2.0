# Проект Bedrock — Лэйауты интерфейса

## Общая структура
Все экраны приложения Bedrock используют единый шаблон с общей верхней строкой меню. Это меню статичное, не изменяется при переключении между экранами.

### Верхняя строка меню:
Содержит 6 пунктов в следующем порядке:
1. Главное (иконка, вероятно в виде домика)
2. Будильник
3. Расписание
4. Погода
5. Свинки
6. Настройки (иконка шестерёнки или звёздочки вместо текста)

**Примечание:** уведомления пока не выносятся в отдельный раздел, но будут отображаться либо в настройках, либо прикреплены к ним.

---

## Темы оформления
Темы определяются на уровне настроек приложения и влияют на визуальное оформление, но не на структуру интерфейса.

### Характеристики темы:
- Цвета элементов управления.
- Общий фоновый рисунок (background).
- Оверлейный слой для каждого раздела (определяется отдельно в каждой теме).
- Цвета и шрифты.

**Важно:** сетка размещения элементов (layout) не зависит от темы и остаётся неизменной.

### Светлая и тёмная версия:
- У темы может быть две версии: светлая и тёмная.
- Переключение между ними происходит автоматически в зависимости от времени суток.

### Рабочая тема:
- В прототипе используется одна тема: **Minecraft**.
- Механизм тем реализуется сразу, чтобы потом не переписывать архитектуру.

## Лэйаут 1: Главный экран (Home)

### Элементы:

- **Верхняя строка меню:** общая для всех экранов (см. выше).

- **Часы:**
  - Расположены по центру экрана.
  - Отображают текущее время в локальном часовом поясе.
  - Крупный шрифт, хорошо читаем издалека.

- **Будильник:**
  - Расположен выше и правее часов.
  - Показывает текущее установленное время будильника и его статус (включен/выключен).
  - Управляется прямо с этого экрана (иконка, кликабельная).
  - Значение по умолчанию: 07:00.

- **Бегущая строка уведомлений:**
  - Расположена под часами.
  - Представляет собой широкое поле.
  - Содержит иконку события, текст уведомления и время события (порядок уточняется).

- **Погода:**
  - Виджет внизу слева.
  - Отображает текущую температуру и иконку состояния (солнечно, дождь и т.д.).

- **Дата и день недели:**
  - Виджет внизу справа.
  - Возможное будущее расширение: статус учебного/неучебного дня (пока не реализован).

## Лэйаут 2: Будильник

### Элементы:

- **Установка времени:**
  - Ввод или выбор времени срабатывания будильника.

- **Статус будильника:**
  - Переключатель включён / выключен.

- **Повторение по дням недели:**
  - Набор чекбоксов (по одному на каждый день недели).
  - Позволяет задать, в какие дни срабатывает будильник.

- **Выбор трека:**
  - По умолчанию используется файл `ring.mp3` из папки `media`.
  - Пользователь может выбрать другой трек из доступных в папке.
  - Интерфейс: список или выпадающее меню треков.

- **Кнопки управления треком:**
  - "Прослушать выбранный трек"
  - "Остановить проигрывание"

- **Действия:**
  - Кнопка "Сохранить будильник"
  - Кнопка "Сбросить будильник" (сброс настроек на значения по умолчанию)

## Лэйаут 3: Расписание

### Источник данных:
- Расписание подгружается из статичного JSON-файла, размещённого в отдельной папке.

### Основные блоки:

- **Текущий день:**
  - Отображается основное расписание на сегодня.

- **Расписание недели:**
  - Отображается вся неделя с возможностью выбрать конкретный день.
  - Выбранный день можно увеличить или развернуть.
  - Возможность листания дней вперёд и назад (реализуется в дизайне).

### Структура расписания:
- Делится на две логические группы:
  1. **Школьные предметы** — основной список уроков.
  2. **Внешкольные активности** — отдельный блок, визуально отделён от первого.

## Лэйаут 4: Погода

### Элементы:

- **Текущий день:**
  - Крупное отображение текущей температуры.
  - Иконка погодного состояния (солнечно, дождь и т.д.).
  - Если погода дождливая, отображается вероятность дождя в процентах.

- **Прогноз на неделю:**
  - Отображается снизу.
  - Представляет собой серию миниатюрных виджетов по дням недели с температурой и погодной иконкой.

- **Дополнительные параметры (если реализуем):**
  - CO₂ и влажность воздуха, получаемые с датчиков Raspberry Pi.
  - Располагаются внизу экрана или в отдельной секции.

---

## Лэйаут 5: Свинки

### Элементы:

- **Три группы параметров:**
  - Вода
  - Еда
  - Очистка
  
Каждый из пунктов включает:
  - **Лейбл** с названием параметра.
  - **Прогресс-бар**, отражающий степень актуальности действия. Прогресс рассчитывается от заданного максимального интервала (например: 2 дня, 3 дня, 4 часа и т.д.).
  - **Кнопка "Сброс"** рядом с прогресс-баром — применяется при выполнении действия (например, напоили — сбросили).

- **Чекбокс:**
  - "Присылать уведомления о событиях" — включает/отключает напоминания по этим действиям.

- **Графика текущего состояния:**
  - Вычисляется интегральный показатель на основе всех трёх прогресс-баров.
  - В зависимости от общего процента выводится одна из ~5 иконок: от счастливой до страдающей свиньи.

---

## Лэйаут 6: Настройки

### Элементы:

- **Выбор темы:**
  - Темы выбираются из предустановленного списка.
  - Если тема только одна (например, Minecraft), выбор недоступен (серый, отключённый).

- **Свойства выбранной темы:**
  - Отображается информация: дневная или дневная+ночная.
  - Флажок "Переключать на ночную тему по таймеру".
  - Таймер может быть реализован как:
    - Жёстко заданное время (например, 20:00).
    - Время заката, получаемое из внешнего сервиса, интернета или локального файла.

- **Лог событий:**
  - Кнопка "Посмотреть лог".
  - В лог записываются все важные события приложения.
  - Интерфейс просмотра будет добавлен позже.
